# 交易审核台 · 前端作品演示

面向银行/支付运营场景的交易审核后台演示，用于展示列表性能、接口层设计与工程化闭环能力。

**在线演示**：https://zhuxiaozhao.github.io/demo-admin/

> 纯前端演示，数据为本地 mock（模拟 320ms 网络延迟），不依赖后端服务。
> 进入方式：登录页点任一角色卡片即可，账号即角色。

## 演示路径（约 2 分钟）

| 页面 | 看什么 |
|---|---|
| 数据概览 | 10 万条数据统计、手写柱状图组件、角色权限差异 |
| 交易审核 | 10 万行虚拟滚动；拖动列表并切换「虚拟化」开关，可见帧率从 60 FPS 掉到个位数 |
| 接口分页 | 服务端分页契约；防抖搜索、切换筛选取消上一次请求、耗时与总条数展示；搜索框输入 `broken` 触发服务端错误，可见错误码 5000、requestId 与重试按钮 |

## 技术点

- **接口层**：统一响应结构 `{ code, message, data, requestId }` 与分页契约 `{ list, total, page, size }`；`fetch` 封装支持 10s 超时、外部 `AbortSignal` 串联、业务错误码分类，按环境变量切换 mock 与真实接口
- **请求取消**：切换筛选会 abort 上一次未完成请求，避免慢请求覆盖新结果
- **列表性能**：虚拟滚动只渲染可视区行（48 行），帧率对比开关可现场演示优化前后差异
- **错误处理**：业务错误码 1001 / 4010 / 5000 分级处理，错误块展示 `requestId` 便于定位
- **质量闸门**：`vue-tsc` 类型检查纳入构建，GitHub Actions 执行 typecheck + build 并归档产物
- **路由**：角色守卫（admin / auditor / guest），hash 模式以适配静态托管

## 技术栈

Vue 3 · TypeScript · Vite · Pinia · Vue Router · 自研虚拟滚动 · GitHub Actions
